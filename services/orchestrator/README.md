# orchestrator

Componente de [AI News Radio](../../README.md).

Usa el `compose.yaml` de la raíz y los scripts de `scripts/`. Las configuraciones
se inicializan desde `config/examples/` y se editan en `state/`. No se despliega
este componente mediante un Compose independiente.

Las notas técnicas específicas se conservan en `docs/` cuando existen.
