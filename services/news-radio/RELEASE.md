# News Radio 1.0.0

Primera versión funcional, identificada por el tag Git anotado `v1.0.0`.

Incluye recogida de noticias por RSS, páginas oficiales y redes sociales,
descubrimiento complementario con SearXNG, biblioteca persistente, redacción y
traducción con Ollama local y atribución oral de la fuente al final del guion.

El código, el catálogo de fuentes, las instrucciones editoriales y la definición
de Docker quedan versionados. `.env`, bases de datos, registros y contenido
descargado permanecen fuera de Git y requieren una copia de seguridad propia.

La ficha del conjunto de servicios está en
`../news-orchestrator/docs/releases/v1.0.0.md`.
